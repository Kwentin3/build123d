# CAD Harness

Это набор инструкций над существующим CAD Lab. Агент читает нужный Skill,
редактирует Python, запускает прежний CLI модели, рассматривает измерения
и выдаёт связанные с ними файлы. Нового процесса исполнения нет.

## Владельцы

| Смысл | Владелец и интерфейс |
| --- | --- |
| Требования, решения, незавершённое | Задание пользователя, README выбранной модели, текущая запись задачи |
| Параметры и геометрия | `models/<name>/model.py`, штатные build123d/Open Cascade |
| Инженерный вердикт | Валидатор и тесты конкретной модели; `report.json` |
| Выполнение и экспорт | Существующие Python CLI и экспортёры модели |
| Обнаружение и загрузка знаний | Нативный Agent Skills host; `.agents/skills/` |
| Редакции и восстановление | Git, исходники, входные параметры и хэши отчёта |
| Просмотр | Уже установленный OCP CAD Viewer, опционально |

Модели plate и gear независимы. Mangal/v2/v21 — явно связанная история
конструкции: v21 повторно использует существующих владельцев геометрии,
экспорта и проверки пересечений. Эта связь не переносится в общие Skills.
Дублирование небольших экспортных/viewer-фрагментов пока дешевле рефакторинга.

## Минимальные изменения

Пять коротких Skills: вход, моделирование, сборки, валидация, производство.
Лазерная резка — один условно загружаемый справочник производства.
Имя/описание доступны при обнаружении; тело читается по задаче; справочник —
при выборе процесса. Каталог не содержит исполняемого стороннего кода.
AGENTS.md даёт короткий вход при работе с новым агентом.

Для актуальности используется существующая схема SHA-256 в `report.json`:
исходники своей модели, явно известные зависимости, выпущенные файлы.
Её получает и plate. В mangal_v21 исключаются старые картинки и документы
из перечня текущего выпуска. Стандартный Python сравнивает хэши перед приёмкой;
отдельного checker, runner или `project-state.json` нет.

Хэши устанавливают соответствие байтов, а не доверие к произвольному Python,
физическую работоспособность или истинность изменённого человеком отчёта.
Параллельное редактирование/генерация одной модели не поддерживается:
сначала закончить запуск, затем менять исходники. Параметры CLI сохраняются
в `parameters`; исходное задание проверяется отдельно.

## Перенос

Формат Agent Skills и Python CLI переносимы. Для Hermes нужно проверить его
штатный каталог Skills и загрузку в реальной версии; затем скопировать эти же
навыки или дать тонкую конфигурационную ссылку. Сейчас Hermes не тестировался.
Linux использует `.venv/bin/python`; версии Open Cascade и результаты экспорта
проверяются заново на целевой платформе. Текущий pinned requirements —
снимок Windows-окружения, не обещание готовой Linux-установки.

До многопользовательского сервера потребуются изоляция сгенерированного Python,
лимиты CPU/RAM/времени, адресная остановка, отдельные каталоги пользователей
и задач, запрет произвольного чтения системных файлов и проверка сторонних
Skills/зависимостей. Это будущая инфраструктура; текущая Windows Job ограничивает
ресурсы, но сама по себе не является файловой песочницей.

Намеренно отсутствуют новый агентный framework, MCP/server, БД, менеджер
моделей/Skills, workflow engine, патчи библиотек и универсальный валидатор.
Первичные источники и ограничения исследования — [AUDIT.md](AUDIT.md).
