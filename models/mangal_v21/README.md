# Мангал 2.1 — пять деталей, без чек

Из выпуска2.0 удалены четыре чеки и их посадочные вырезы в верхних выступах.
Комплект: две продольные стенки, два торца с ножками и съёмное дно.
Три уникальных DXF: `side.dxf` ×2, `end.dxf` ×2, `bottom.dxf` ×1.

Верхние V-посадки40° от вертикали и нижние свободные направляющие сохранены.
Суммарные нижние зазоры:0,6 мм по толщине и1,2 мм по вертикали.
Габариты жаровни500 ×300 ×160 мм; лист3 мм. Все размеры редактируются через
`Params` в начале `model.py`, без изменения сохранённого выпуска2.0. Новых зависимостей нет.

```powershell
.\.venv\Scripts\python.exe models/mangal_v21/model.py --screenshots
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe models/mangal_v21/documentation.py
```

Разборка: приподнять обе стенки примерно на0,5 мм → снять второй торец →
выдвинуть дно → выдвинуть приподнятые стенки из первого торца.
Сборка в обратном порядке; после установки торцов опустить стенки в V-посадки.
Требования к микронной точности ручного движения нет: поднять до свободного выхода.

V-зацепы удерживают торец при опущенных стенках. После подъёма стенок дополнительной
блокировки нет — это осознанное упрощение. Устойчивость к случайному разъединению,
физическая сборка и разборка после нагрева проверяются на опытном комплекте.
Собранный мангал не использовать как переносную тару для топлива.

Результаты в `output/mangal_v21/`: STEP из пяти тел, три DXF1:1 в мм,
спецификация, инструкции, отчёт, снимки, PDF. Предыдущие версии в `models/mangal/`,
`models/mangal_wedge/`, `models/mangal_v2/` и их результаты сохранены по SHA-256.
Геометрические утилиты и условная механика повторно используются через прежних владельцев.
