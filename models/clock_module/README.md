# Модуль TFA 60.3065.02 и часы в сборе

Габаритная модель покупного модуля для просмотра готового изделия в трёх
корпусах из `models/clock_family`. Используется их текущая редакция с задними
крышками и саморезами; габаритная геометрия самого OEM-модуля сохранена.
Размеры в мм; +Y вверх, +Z назад, условная опорная плоскость модуля Z=0.

Изготовитель подтверждает общий габарит Ø90 × 36 и установочный Ø77 × 22.
Белый циферблат, серебристый обод, чёрные часовая/минутная стрелки и золотистая
секундная показаны приближённо по официальной фотографии. Стрелки выставлены
на 10:10:30. Это отдельная покупная деталь, не часть печатного корпуса.

Положение буртика внутри общего габарита неизвестно. Деление глубины на
14 мм спереди и 22 сзади — условность иллюстрации, сохранённая с предыдущего
изображения. Размеры декоративных деталей и задний цилиндр упрощены.
Стекло, штатное монтажное кольцо, механизм и AA не воспроизводятся. Саморезы
показаны номинальными габаритами; заводские резьбы и приводы не моделируются.
Не моделируется выдуманная резьба; реальная посадка и удержание NOT_CHECKED.

Первоисточники, проверены 2026-11-18:

- [Изделие и технические данные TFA](https://www.tfa-dostmann.de/en/product/analogue-quartz-clock-60-3065/).
- [Официальное фото](https://www.tfa-dostmann.de/wp-content/uploads/24607-60f6b7ccd7dae-scaled.jpg).
- [Инструкция: установочные размеры, питание и обслуживание](https://com-tradebyte-core-tbone-media-live.s3.eu-central-1.amazonaws.com/media/1768/25729-618bd19257933.pdf).

Запуск из корня через общий Windows executor (один `heavy:clock-module`,
срок до 900 секунд, штатные лимиты 2 GiB/32 процесса, остановка по RunId):

```powershell
.venv/Scripts/python.exe models/clock_module/model.py --screenshots --browser "C:/Program Files/Google/Chrome/Application/chrome.exe"
.venv/Scripts/python.exe -m pytest -q
```

Новая служба не запускается: снимки получает уже работающий OCP Viewer.
Chrome работает в том же managed дереве; временный профиль
`<output-dir>/chrome-profile` удаляется после подтверждения завершения.

Результаты в `output/clock_module`: `module.step`, размерный лист
`module-drawing.svg/pdf/png`, три `*-assembled.step` и снимки, общий лист
`assembled.pdf/png`, виды сзади `rear.pdf/png` и разнесённые виды
`exploded.pdf/png`. Последние поясняют состав, а путь снятия проверяется отдельно.
STEP сборок содержит покупную деталь и не предназначен
для печати целиком. Размерные проекции получены штатным OCCT HLR, цветные
виды — OCP CAD Viewer. `report.json` связывает источники и файлы SHA-256.

Проверяются габариты модуля, установочный цилиндр, валидность, отсутствие
пересечения с текущими корпусами и повторный импорт всех четырёх STEP.
Эти проверки относятся только к показанной номинальной геометрии.

STEP проверяются последовательно в дочерних процессах того же managed Job,
чтобы освобождать память OCCT между файлами. У каждого импортированного тела
сверяются габариты, объём, площадь и центр; для механических тел объёмом
более 1000 мм³ дополнительно вычисляется булева симметрическая разность.
Мелкие отдельные метки проверяются по указанным геометрическим признакам.
