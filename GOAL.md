# Agent-Native CAD Harness

Статус: завершено; локальная поставка принята независимым ревью.

Цель: оформить существующий CAD Lab в минимальный переносимый Harness без
переписывания моделей, нового сервера, MCP, фреймворка или зависимостей.

Поставка: ARCHITECTURE.md, WORKFLOW.md, AUDIT.md, обновлённый README.md,
нативные Agent Skills и минимальные правки существующих отчётов.
Приёмка: исходный CAD работает; Skills реально обнаружены; простое изменение,
анализ сборки и FAIL → исправление проверены; устаревший отчёт не принимается.
Мангал и существующие output сохраняются; VPS вне объёма.

Решения: Python остаётся источником геометрии; требования и отчёты принадлежат
модели; файлы и Git восстанавливают контекст. Skills — инструкции, не runtime.
Все локальные процессы запускаются через общий Windows executor: 2 GiB,
32 процесса, один heavy, явный срок и адресная остановка RunId.

Проверенное состояние: в исходной папке Git отсутствовал; создан локальный
baseline commit и output/harness/baseline-sha256.json для моделей и результатов.
Есть plate, gear, mangal, mangal_wedge, mangal_v2, mangal_v21. Установлен
Codex IDE/CLI 0.169.0-alpha.11.1. Инвентаризация и исследование завершены.

Проверено дополнительно: инвентаризация и исследование завершены (AUDIT.md).
Все пять SKILL.md прошли штатный quick_validate без установки зависимостей;
валидатор выполнен существующим системным Python, потому что CAD venv не
содержит PyYAML. CAD и тесты используют только проектный venv.
Python 3.13.7, build123d 0.13.0, OCCT 8.0.1.1.0, ocp_vscode 4.2.0,
pytest 9.2.0; pip check успешен. Созданы ARCHITECTURE.md и WORKFLOW.md,
обновлены README/AGENTS и pytest discovery VS Code.

Открытых обязательных пунктов нет. Независимая приёмка: PASS по всем шести
группам требований. Поставка сохраняется в локальном Git; исходная точка
восстановления и evidence контрольных испытаний сохранены.

Уточнение пользователя: максимально KISS и нативно. Обвязка запуска отменена
до реализации. Используются прежние CLI и существующая схема SHA-256 отчётов;
новых tools, реестров, форматов состояния и диспетчеров не добавляем.
Пять Skills уже появились в нативном каталоге навыков текущего Codex после
создания файлов; выборочная загрузка затем проверена контрольными сценариями.

Минимальная корректировка отчётов внесена: plate получает существующий формат
SHA-256; v21 перечисляет только завершённые экспортные стадии, документация
требует текущую привязку снимков. Геометрия и CLI не менялись.

Приёмка: все три сценария завершены; свежий независимый контекст пластины
обнаружил Skills и прочитал только entry/modeling/validation. WIDTH110 →
реальное смещение отверстия → stale старого PASS → FAIL → исправление → PASS.
Сборочный вариант в памяти прошёл 28/28 проверок; исходная конструкция сохранена.
Штатные CLI обоих контрольных изделий успешны, STEP повторно проверен,
27 привязок отчётов совпали. Все 112 прежних output-файлов неизменны.
Первый общий pytest захватил архивные копии; исправлено нативным pytest.ini
с testpaths=tests models. Повтор: 70 passed за 337,27 с, код 0.
Временная рабочая копия и диагностические схемы удалены; stage evidence
сохранён в output/harness. Полные результаты и ограничения — AUDIT.md.
