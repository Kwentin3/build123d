# Публикация CAD Harness в GitHub

Статус: подготовка. Назначение — https://github.com/Kwentin3/build123d.
Исходная локальная опора: 4d7a1fc; предыдущие завершённые GOAL сохранены в Git.

Объём: существующие исходники, пять Skills, инструкции/workflow/настройки,
все модели и тесты, экспорт/документация и небольшой набор полезных примеров.
Русский README должен позволять установить окружение и воспроизвести проверки.
Код CAD, зависимости и архитектуру не менять без наблюдаемого препятствия.

Полномочия: история сохраняется; force push и удаление чужого запрещены.
Remote публичный и пустой, write-доступ подтверждён. Перед первой отправкой
показать точный состав и получить отдельное подтверждение пользователя (п.8).
До него разрешены локальная подготовка, коммиты и проверки, но не публикация.

Проверено: три существующих коммита/63 разных blob не содержат найденных
секретов, личных абсолютных путей или мусора; историю переписывать не требуется.
Все 68 pinned packages доступны в PyPI с совместимыми Windows/Python3.13 wheels.
Обнаружена зависимость full pytest от output/mangal: в README будет явно
указан запуск исходного mangal перед тестами, без изменения работающего кода.

Решения: обычный output остаётся локальным; только output/examples отслеживается.
Примеры PDF/PNG и CAD сохраняют историческую дату и байты. Производные отчёты
с относительными путями явно не подтверждают текущую source binding.
Исходные локальные результаты не перезаписываются. Логи/среды/секреты исключены.

Обязательный остаток:
1. Закончить README и curated examples, сверить состав/хэши и содержимое.
2. Проверить чистое восстановление, свежую установку, модели/STEP и полный pytest.
3. Проверить финальную историю/файлы на приватные данные; убрать временное,
   показать точный коммит/состав и запросить разрешение публичной публикации.
4. После подтверждения отправить без force и сверить remote с локальным commit.

Ресурсы: managed Windows executor, один heavy, 2 GiB/32 процесса,
установка с wheels без компиляции, срок до 900 с; остановка/наблюдение по RunId.
Следующий шаг: подготовить точный локальный кандидат для чистой проверки.
