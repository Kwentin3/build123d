# Контроль функции обслуживания

[filter-control.zip](filter-control.zip) содержит редактируемый учебный
держатель фильтра, model-owned evaluator, тесты, шесть STEP двух вариантов
и привязанный SHA отчёт. CONTENTS.json позволяет сверить файлы архива.

Исходная конфигурация имеет валидный BREP и свободные начальную/конечную позы,
но заданный непрерывный путь замены перекрыт: service FAIL. В отдельном варианте
путь свободен: service PASS. Прочность и изготовленная посадка NOT_CHECKED.
Статус experiment_status=PASS означает корректное выявление ожидаемых исходов,
а не одобрение исходной конструкции.

Архив — дополнение к [исследованию и независимому переносу](../../../docs/engineering-review/README.md).
Это учебная геометрия, не изделие для изготовления. Часы из PR #2 здесь отсутствуют.
