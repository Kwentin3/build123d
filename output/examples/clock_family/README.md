# Три корпуса часов — снимок эксперимента 2026-11-18

Модуль: TFA Dostmann 60.3065.02, AA. Установочный габарит изготовителя Ø77 × 22;
проектная посадка Ø77.4 × 22. Это номинальные прототипы, не производственный
выпуск. [Первичные источники и неизвестное](../../../models/clock_family/SOURCES.md),
[исходники, сборка и повторный запуск](../../../models/clock_family/README.md).

- [Общий вид](overview.png).
- [Архив STEP/STL, SVG/HTML/PNG и отчётов](clock-family-prototype.zip).
- [Переносимая сводка с SHA](example-report.json).

Приёмка исходников `fa1d6ff`: **125 passed**, 426.20 с, чистая копия без
прежних runtime outputs; 84 tracked-файла совпадали с рабочими по байтам.
Базовый выпуск: 109 PASS / 0 FAIL / 18 NOT_CHECKED. Эксперимент: 108 PASS /
0 FAIL / 18 NOT_CHECKED, Change Safety PASS. Шесть вспомогательных STEP с
установочным объёмом также проверены после импорта. Архив: 77 файлов, 2.1 MB.

Первый запуск в прежней рабочей папке дал 124 passed / 1 failed из-за уже
устаревшего локального манифеста mangal_v21: два исходника wedge не совпадают
с его историческими хэшами, но совпадают со снимком до этой задачи. Старый
манифест и все 333 защищённых файла оставлены без изменений.

Архив распаковывается в отдельный checkout: `output/clock_family/baseline/`,
`output/clock_family/change/` и `models/clock_family/`. Для печати подходят только
`body.stl` и `portable/lid.stl` соответствующего варианта. Файлы
`with_installation_envelope.step` содержат дополнительный покупной установочный
объём и не являются печатной сборкой. STEP/STL корпуса не включают покупные
часы и винты. SVG/HTML показывают модуль условно; `viewer.png` — настоящие
снимки OCP Viewer собственных деталей.

В `baseline/report.json` и `change/report.json` записаны измерения, STEP/STL
round trip, источники/зависимости и SHA артефактов. `change/change-report.json`
сравнивает кандидата с отдельными принятыми STEP, фиксирует ожидаемые
отрицательные случаи и сохранение базы. Диаметр меняется Ø77.4 → Ø78.0;
прочие формы и положения защищены. В `example-report.json` — фактический
результат полного pytest и проверки сохранности прежних файлов.

Открытые NOT_CHECKED: удержание и допуски OEM-кольца, реальный ход задней
крышки/батареи и место для пальцев, прочность, падение, нагрев, FDM-посадка,
анкеры и физическая устойчивость. Следующий инженерный шаг — образец модуля
и короткий купон посадки. Эксперимент не требовал новых зависимостей или
изменения CAD Harness.

Снимок сохраняет фактические байты выпуска; обычный повторный запуск пишет в
`output/clock_family/` и не заменяет опубликованный архив. После checkout
сверьте source/dependency/artifact SHA: преобразование переводов строк тоже
делает старую привязку неактуальной. Для новой приёмки выполните команды из
README модели, прочитайте FAIL/NOT_CHECKED и откройте текущие изображения.
