# Проверка держателя сменной фильтрующей кассеты

Дата: 2026-11-18. Итог: **FAIL для заданной замены кассеты**. При неподвижной рамке прямой ход кассеты на 90 мм по +Y без вращения и смещений X/Z перекрыт поперечиной. Конструкцию и входные файлы не изменяли. Валидность тел и отсутствие пересечения в начальной/конечной позах не подтверждают обслуживаемость.

## Требование, метод и результат

Источник требования — models/filter_holder/README.md. Кассета моделирует полный габаритный объём, поэтому пересечение с поперечиной нельзя объяснить пористостью фильтра. Внешнее место для всего хода предоставлено по заданию; окружающий корпус не моделировался. Обратная установка требует пройти тот же заблокированный путь.

Из model.py штатной функцией make_holder() построены BREP build123d 0.13.0 / OCP 8.0.1.1. Оба тела валидны, каждое содержит один solid. Рамка: X[-37,37], Y[-47,47], Z[-1,19]; кассета: X[-25,25], Y[-35,35], Z[6,14], объём 28000 мм³. Координаты и расстояния — мм.

| Проверка | Измерение | Область вывода |
|---|---|---|
| Установленная кассета | Пересечение с рамкой 0 мм³ | Номинальная поза геометрически возможна |
| Боковое пространство | По 2 мм слева/справа | Номинальный зазор; предельная производственная посадка не проверена |
| Задняя пластина | Зазор по Z 5 мм | Кассета в номинальной позе на неё не опирается |
| Нижняя полка | Зазор по Y 0 мм, контакт | Есть геометрическая опора вниз; её прочность не проверена |
| Поперечина сверху | Начальный зазор по Y 4 мм | После 4 мм хода начинается упор |
| Заданный ход | Положительный объём пересечения для 4<s<80 мм | **FAIL**, прямое извлечение и обратная установка невозможны для жёстких номинальных тел |
| Конец хода s=90 | Пересечение 0 мм³, расстояние 8.246211 мм | Конечная поза свободна, но путь к ней перекрыт |

Численная проверка выполнена штатными boolean intersection и distance_to. При s=4.001 мм пересечение 0.400000 мм³; при s=10,45,74 мм — 2400 мм³; при s=79.999 мм — 0.400000 мм³. При s=4 и80 — касание без положительного объёма.

Для непрерывного хода использована **точная огибающая**, а не только дискретные позы: исходник задаёт кассету одним осевым прямоугольным Box. Его объединение при переносе на [0,90] по +Y — Box 50×160×8 с границами X[-25,25], Y[-35,125], Z[6,14]. Пересечение этой огибающей с фактической рамкой имеет границы X[-25,25], Y[39,45], Z[6,14] и объём 2400 мм³. Вне поперечины объём препятствия 0 мм³. Для этих осевых призм объём пересечения в позиции s равен:

V(s)=400·max(0,min(35+s,45)-max(-35+s,39)) мм³.

Отсюда первое касание при s=4; положительное пересечение на (4,80); максимум 2400 на [10,74]. Вращение, отгибание поперечины, снятие рамки и боковое извлечение не входят в разрешённую операцию. Деформация не использована для обхода установленного препятствия.

## Ограничения и вопросы заказчику

Дополнительные данные были запрошены у представителя заказчика через collaboration.send_message до измерений. Ответ: данных нет; физическое одобрение этих свойств не требуется, условия замены и предоставленное внешнее пространство остаются по README.

- **Удержание в эксплуатации — NOT_CHECKED.** Нижняя полка даёт контакт вниз, но сам номинальный просвет не подтверждает фиксацию от выпадения, дребезга или смещения. В текущей модели не показан передний захват кассеты по Z; это наблюдение, а не самостоятельный FAIL без требований к удержанию. Нужны разрешённые перемещения, ориентация, направление/величина нагрузок и требуемый способ фиксации; далее — соответствующая геометрическая проверка и испытание.
- **Прочность, усилие извлечения, ресурс и среда — NOT_CHECKED.** Нужны материал, нагрузки/перепад давления, масса, коэффициенты запаса, температуры, влажность, вибрации и число циклов. Затем расчёт/испытание в заданных условиях. Геометрические контакты не доказывают несущую способность.
- **Посадка изготовленных деталей — NOT_CHECKED.** Нужны процесс, предельные размеры кассеты и рамки, геометрические допуски и требуемые рабочие зазоры. По 2 мм в CAD нельзя объявить гарантированной посадкой.
- **Удобство ручного захвата, усилия и реальная замена — NOT_CHECKED.** Нет требований к захвату, перчаткам и доступу руки. После устранения противоречия с заданным ходом необходима физическая проверка согласованной операции; одна геометрия её не заменяет.
- Крепление рамки к корпусу и реальная работа фильтра прямо исключены README из аттестованного объёма. Они не объявлены проверенными. Новые численные нормативы и рейтинги риска не назначались.

Главное уточнение для продолжения: заказчику необходимо согласовать, каким образом конструкция должна обеспечить уже заданный свободный ход +Y90. Текущая геометрия ему противоречит независимо от отсутствующих материалов и допусков. Изменения конструкции, способа замены и альтернативные траектории в этой проверке не выполнялись и не принимались.

## Воспроизводимость и evidence

- Исходник: models/filter_holder/model.py, SHA-256 **b8ab7d74988ae7c5a01ba8111fc12594e0e4b9eac673d8d36aba9d20402a598c**.
- Фактически выполненный код: measure.py; результат: measurements.json. JSON содержит SHA исходника и скрипта, версии, границы измерительных проб, BREP и величины пересечений. После измерения SHA исходника повторно проверен.
- Дополнительный список прочитанных файлов и их текущие SHA: read-inputs.json. Skills применены непосредственно из назначенной копии pilot-input, а не из соседних рабочих копий.
- Анализ касается BREP, построенного из исходника. STEP, изображения, экспорт, pytest и физические испытания не выполнялись; готовность к изготовлению не заявлена.
- Первый запуск вычислил геометрию, но остановился при чтении metadata отсутствующего distribution cadquery-ocp. Это техническая ошибка маркировки среды. RunId 5a782cc251654ad5bc48b8907a3926d2: exit=1, reason=exited, cleanup=confirmed. В собственном скрипте версия заменена на импортированный OCP; последовательный повтор завершился exit=0. Ошибка сохранена отдельно в execution-notes.txt и не трактуется как инженерный FAIL.

Исходная причина функционального отказа — расположение неподвижной поперечины внутри предписанного пути кассеты. Это проверенный геометрический результат; прочность и физические свойства остаются открытыми по перечисленным причинам.
